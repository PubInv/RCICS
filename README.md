# RCICS
Rapid Contact Isolation Containment System (RCICS)

This is an attempt to design a system for Ebola infection containment which can be 
placed inside a door frame to support the Ebola crisis.

This is an offshoot of Michael Min's FlexContain project of Helpful Engineering, which
pre-existed the current Bundibugyo strain outbreak of Ebola in the Congo (and a conatined outbreak in Uganda.)

## Basic Ideas

1. Either shim something into the frame, or modify the door.
2. Create a "port module" which is standardized that can be used in any door-like structure.
3. Create a "tubing module" that goes near the hinge side that puts minimum motion on tubes passing through the door as it is opened or closed.
