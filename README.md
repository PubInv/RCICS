# Rapid Contact Isolation Containment System — RCICS

RCICS is an open source effort to develop a locally fabricable
door-replacement assembly for temporary contact/droplet isolation spaces.

> RCICS is not an airborne-isolation or negative-pressure system.
> The current designs have not been validated or approved for clinical use.
